# 리뷰 스튜디오

제품 리뷰 사진용 독립 웹앱. 별도 서버나 API 키 없이 브라우저에서 사진을 처리합니다. 새 사이트는 소유자만 접근하는 비공개 상태로 게시합니다.

## 기능

- 최대 20장 불러오기, 기기 내부 IndexedDB에 편집 상태 보관
- 밝기·대비·채도·색온도·어두운 부분 조절, 프리셋 3종, 전체 밝기 기준 자동 보정
- 현재 사진의 색감만 다른 사진에 일괄 적용
- 원본 비교, 원본으로 초기화, 최근 편집 되돌리기(최대 6회)
- 원본·1:1·3:4·4:3·16:9 자르기와 위치 조절, 90도 회전
- 선택한 지점과 연결된 비슷한 색 배경 지우기, 지우개, 원본 복원 브러시
- 투명·단색·직접 선택한 색·불러온 사진으로 배경 교체
- 깨끗한 영역을 복사해 작은 물건이나 얼룩을 덮는 부드러운 복사 브러시
- JPEG/PNG 내보내기, 지원 브라우저에서 사진 파일 공유, 여러 장 ZIP 다운로드
- 홈 화면 설치용 manifest와 아이콘, 첫 접속 후 정적 파일 오프라인 캐시
- 모바일/데스크톱 화면 대응, 직접 체험할 수 있는 가상 제품 샘플

## 알아둘 점

이 버전은 생성형 AI 편집기가 아닙니다. 배경 지우기는 색상 기반의 연결 영역 선택이며, 복잡한 배경이나 제품과 비슷한 색 영역은 수동 브러시로 다듬어야 합니다. 물건 제거는 주변 영역을 복사하는 방식입니다. 복잡한 배경 재생성·의미 기반 피사체 인식·생성형 채우기는 포함하지 않습니다.

편집 해상도는 긴 변 최대 2,400px입니다. 가져온 원본 파일이나 기기의 사진 앱 파일은 변경하지 않고 별도 보정본을 만듭니다. 앱의 ‘원본’은 편집 해상도로 정규화한 사진입니다. 실제 상품의 색·로고·재질이 달라지지 않았는지 원본과 비교하세요.

사진은 서버로 전송하지 않습니다. 해당 브라우저·사이트의 기기 내부에 보관되며 사이트 데이터 삭제, 브라우저 정리나 저장 공간 부족에 영향을 받을 수 있습니다. 완성본은 별도로 저장하세요. 되돌리기 기록은 재실행하면 초기화됩니다.

아이폰 사진 앱에 저장: **사진 저장 → 저장 파일 만들기 → 사진 앱으로 저장·공유 → 이미지 저장**. 실제 공유 대상과 지원 여부는 기기에 따라 다릅니다. JPEG는 투명 부분이 흰색으로 저장됩니다. 투명 영역이 필요하면 PNG를 선택하세요.

## 실행과 배포

의존성 설치나 빌드가 필요 없습니다. `dist/` 전체가 사이트입니다.

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory dist
```

Render Static Site로도 배포 가능합니다. Build Command `echo "No build required"`, Publish Directory `dist`. 사진을 읽고 파일 공유를 사용하려면 HTTPS 또는 로컬 개발 환경에서 실행하세요. HTML을 파일로 직접 여는 방식은 지원하지 않습니다.

## 검증

- `npm test`: 색감 기본값 무변경, 노출, 투명도 보존, 흑백 변환, 자동 밝기 범위, 다양한 자르기 경계, 연결 배경 제거와 행 경계 누출 방지, ZIP CRC 검사
- 생성 ZIP을 Python zipfile로 열어 한글 파일명과 원본 바이트 일치 확인
- 브라우저: 샘플 추가·기기 보관, 배경 선택 지우기와 되돌리기, 복사할 지점 선택·브러시 적용, JPEG 준비, 여러 장 ZIP 준비 확인
- 390px 모바일에서 가로 넘침 없음, 데스크톱 1440px에서 레이아웃 수치 확인
- 실제 아이폰의 사진 앱 저장, 대용량 사진 다수 처리, 복잡한 배경의 품질은 대상 기기에서 별도 확인 필요
